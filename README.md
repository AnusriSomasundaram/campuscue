# 🎓 CampusCue — Smart Campus Study Companion

CampusCue is a student-focused web application that helps students organize their academic activities, manage deadlines, plan study sessions, and collaborate with peers in one place.

## ✨ Features

- 📊 **Smart Dashboard** — View important academic information at a glance.
- 📅 **Deadline Management** — Keep track of upcoming assignments and deadlines.
- 🧠 **Smart Study Planner** — Organize study tasks and plan your workload.
- 📈 **Workload Insights** — Understand and manage your academic workload.
- ⏱️ **Focus Timer** — Support focused and productive study sessions.
- 🗓️ **Calendar View** — Keep academic activities organized.
- 👥 **Collaborative Study Groups** — Join and leave groups to connect with peers.
- 💬 **Real-Time Group Chat** — Communicate with study group members.
- 🔐 **User Authentication** — Sign up and log in using Firebase Authentication.
- 🌙 **Dark Theme** — A modern interface designed for comfortable use.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Deployment:** Vercel

## 🎯 Objective

To bring essential academic organization and peer collaboration tools together in one accessible platform, helping students build better study habits and manage their academic responsibilities efficiently.
